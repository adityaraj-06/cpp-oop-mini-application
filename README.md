# 🎓 Student Search System — C++

A beginner-friendly C++ console application built to practise Object-Oriented Programming and student record management.

## 📌 About the Project

The Student Search System is a mini project developed while learning C++. It demonstrates how programming concepts can be applied to organize student information and search for a student using a roll number.

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** Classes, Objects, Constructors, Conditional Statements, and Loops (where implemented)
- **Environment:** Visual Studio Code

## ✨ Features

- Stores student information such as name, age, roll number, and number of subjects.
- Searches for a student using a roll number.
- Displays student details when a matching record is found.
- Handles cases where a matching student is not found, if implemented in the current version.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Compile the C++ source file using a C++ compiler.
4. Run the generated executable.
